# 2026-Reyeros-Editor-de-Imagenes
Aplicación de escritorio para edición y procesamiento de imágenes con envío por correo electrónico vía SMTP. Desarrollada en Python con Tkinter y Pillow para la asignatura Programación II (5.º año - IPETYM N° 246). Incluye vista previa dinámicas, historial ilimitado (Undo/Redo), retroalimentación sonora y compilado ejecutable (.exe).
